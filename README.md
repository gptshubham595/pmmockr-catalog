# PMMockr public practice catalog

This repository contains PMMockr's generated, allowlisted public question catalog.
It is consumed server-side by the PMMockr API for question titles and basic metadata.

It intentionally excludes question descriptions, prompts, solutions, rubrics,
evaluation criteria, private interviewer context, and user data.

- [PMMockr](https://www.pmmockr.com)
- [Practice library](https://www.pmmockr.com/practice)
- [PM interview questions](https://www.pmmockr.com/interview-questions)
