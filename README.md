## Why PMMockr

- PM-specific case library (not generic interview chat)
- Timed interviewer mode with follow-ups
- Session feedback you can turn into the next drill
- Built for APM / PM / senior PM candidates who need reps, not more theory

## This repository

Public **safe practice catalog** (CDN mirror). Content-hashed JSON only. Generated by `scripts/export-safe-catalog.mjs`.

No solutions, rubrics, or private interviewer fields.
